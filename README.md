# Secure-Enterprise-Network
A multi-VLAN enterprise network infrastructure built in Cisco Packet Tracer, featuring inter-VLAN routing, OSPF dynamic routing, DHCP, NTP, EtherChannel (LACP), Spanning Tree Protocol (STP), ACLs, and Layer 2 security mechanisms including Port Security, DHCP Snooping, and Dynamic ARP Inspection (DAI).
